# NETRA — Multi-Agent Defense Intelligence Engine (IKKEP)

**Domain:** Pertahanan / geopolitik
**Tagline:** Mesin analisis skenario geopolitik untuk ketahanan defense-ekonomi Indonesia.
**Jumlah agent:** 28 (paralel)

## Apa Ini
Menganalisis skenario geopolitik kompleks untuk menilai ketahanan defense-ekonomi Indonesia. Mensimulasikan dampak kebijakan, melacak ancaman regional, dan menghasilkan rekomendasi strategis lintas dimensi pertahanan, ekonomi, dan diplomasi.

## Fitur Utama
- 28 agent paralel diorkestrasi lewat pipeline terspesialisasi.
- 10 varian pipeline (policy simulation, country analysis, bilateral relations, regional intelligence).
- 4 Strategic Quadrant (pemetaan postur: assertive/cooperative/absorbing/distant).
- Threat watch real-time + threat matrix aggregation.
- Pelacakan 28 indikator defense-ekonomi lintas dimensi.
- Analisis intelijen institusional & regional (6 region, 18+ organisasi).
- Tiga mode respons pertahanan (Absorb, Evade, Empower).

## AI Agents (28)
Policy agents (simulasi, impact, rekomendasi), country analysis agents, bilateral relation agents, indicator processors (28 metrik), intelligence aggregators (threat matrix, wiki synthesis), regional & institutional analyzers.

## Tech Stack
GPT-4 (OpenAI) + OpenRouter dengan fallback; BaseAgent dual-model; embeddings untuk semantic analysis; structured streaming policy impact; database indikator defense-ekonomi.

## Metrik Penting
28 agent paralel · 10 pipeline · 8 country/bloc analysis · 4 quadrant · 28 indikator · 3 mode pertahanan · 18+ organisasi dipantau.
