# Foto profil

Letakkan foto Anda di folder ini dengan nama **`profile.jpg`** (atau `.png`/`.webp` lalu
sesuaikan path di `src/components/Avatar.tsx`).

- Ukuran disarankan: ~400×400px, format WebP/JPG.
- Jika file tidak ada, avatar otomatis fallback ke inisial "F" (tidak error).
- Efek blur→sharp on hover sudah otomatis diterapkan.
