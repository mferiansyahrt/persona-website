Core Framework

The IKKEP
Four-Quadrant Model

Every simulation maps Indonesia’s position onto a two-axis strategic space. The X-axis measures external threat intensity (ILAG — 10 indicators), and the Y-axis measures internal defense resilience (IKGP — 18 indicators). Threshold: 50.0.

↑ IKGP High (Strong Resilience)
Optimal Stability
Low threat, high resilience. Ideal state — Indonesia is well-defended with minimal external pressure.
High Pressure Resilience
High threat, high resilience. Under pressure but capable of absorbing shocks.
Latent Risk
Low threat, low resilience. Deceptive calm — vulnerable if conditions deteriorate.
Vulnerable
High threat, low resilience. Crisis state — immediate intervention required.
← ILAG Low (Low Threat)    —    ILAG High (High Threat) →
Capabilities

What It Does

A single scenario triggers a chain of intelligent agents working together to assess threats, measure resilience, and recommend strategic actions.

🌎

Scenario Impact Simulation

Input a geopolitical event (e.g., “China imposes rare earth embargo on ASEAN”). The engine assesses how all 28 defense-economic indicators shift, determining Indonesia’s new strategic position.

🕵

Country Strategic Profiling (V3)

Deep-tag any country with baseline orientation analysis (outside-in/inside-out), then classify across 10 strategic layers from 3 geopolitical perspectives (SQPP, RPP, GSP). Quantitative scoring (0–10) with convergence/divergence synthesis across perspectives.

🤝

Bilateral Relations Matrix

Score any country pair across 4 dimensions: ekonomi, politik, keamanan, sosial-budaya. Scale from -5 (war) to +5 (special relationship), with zone classification (Konflik to Integrasi).

🛠

Policy Simulation

Choose Absorb, Evade, or Negotiate. Each mode projects how indicator scores change with strict scoring rules. Absorb boosts IKGP immediately; Negotiate reduces ILAG diplomatically; Evade restructures gradually.

📖

Country Wiki & Doctrine Impact

Generate encyclopedic profiles (geography, economy, politics, security, history) for any country, then analyze how one nation’s doctrine impacts another through historical and contemporary lenses.

🔮

What-If Scenario Analysis

Project alternative futures: de-escalation, status quo, or escalation pathways. Multi-phase scenario progression with stakeholder analysis, risk assessment, and probability scoring.

Pipeline Workflow

The 10-Step
Simulation Pipeline

From a plain-language scenario to a comprehensive strategic assessment — here is what happens behind the scenes.

1

Validate Database Indicators

The engine queries PostgreSQL to check which of the 28 indicators (10 ILAG + 18 IKGP) have available historical data. Only indicators with real data in the kemhanxnsi schema are activated.

ilag_long_fix ikgp_long_full asyncpg
2

Fetch Baseline Scores

For each validated indicator, the system fetches the current normalized score (0–100 scale) from the database using CTE-based SQL. These baselines represent Indonesia’s “before scenario” state.

🔎 Optional Step 2.5: If specific countries are requested, CountryWatchAgent runs in parallel to deep-profile each country across 8 strategic layers. This context is injected into all downstream indicator agents for richer analysis.
3

Build Agent Tasks

The INDICATOR_REGISTRY (28 entries) is loaded. Each indicator gets an IndicatorAgent instance with its specialized prompt module (SYSTEM_PROMPT + HUMAN_PROMPT_TEMPLATE), the baseline score, the scenario, and optional country watch context.

10 ILAG Agents 18 IKGP Agents Parametrized Polymorphism
4

Execute 28 Agents in Parallel

asyncio.gather(*tasks) launches all 28 indicator agents simultaneously. Each agent calls the LLM with its specialized prompt, uses KnowledgeRepositoryTools for real-time data search, and returns a structured JSON result with new score, confidence, reasoning, and per-country analysis.

⚙ Fallback Safety: If any agent fails, a safe fallback result is returned (baseline score passthrough, is_affected=false, confidence=LOW). Individual failures never break the pipeline.
5

Aggregate & Determine Quadrant

All ILAG scores are averaged to get avg_ilag; all IKGP scores to get avg_ikgp. The determine_quadrant() function maps these two values against the threshold (50.0) to one of four strategic positions.

6

Position Analysis

The PositionAnalysisAgent receives the aggregated scores, quadrant label, and all individual indicator results. It generates a strategic description of Indonesia’s position and a causal narrative explaining the chain of events.

7

Strategic Mitigation Mandate

The StrategicMitigationAgent analyzes the scenario, position, and all affected indicators to produce a single, imperative mitigation mandate — tegas, spesifik, dan terprioritaskan.

8

Compose Output & Country Summary

All results are merged into a comprehensive JSON. Optionally, the CountrySummaryAgent synthesizes country analysis from all 28 agents into compact markdown. Results are saved to simulation_results/{date}.json.

9

Infographic Generation

The InfographicAgent converts the simulation JSON to structured markdown, then HTTP POSTs it to an external infographic service. Returns S3 URLs for HTML dashboard, PDF report, and PPTX presentation.

HTML Dashboard PDF Report PPTX Presentation
10

Deliver Results

The complete simulation result is returned via FastAPI response, stored in Redis for async consumers, and served through MCP for Stellar chat integration. Multiple delivery channels ensure the analysis reaches decision-makers instantly.

REST API Redis Queue MCP / Stellar Chat Streamlit Dashboard
